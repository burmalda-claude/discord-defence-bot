# Политика конфиденциальности discord-defence

Последнее обновление: 3 ноября 2026 г.

## Какие данные хранятся
Для каждого сервера, где установлен бот, на сервере бота сохраняются:
- **Резервные копии структуры сервера:** название, иконка и настройки сервера; роли (название, цвет, права, позиция) и **ID участников, у которых есть роль**; каналы и категории (название, тема, настройки, права доступа, включая ID участников с индивидуальными правами).
- **Настройки бота:** лог-канал, белый список (ID пользователей), параметры защиты.
- **Время последней работы бота** — чтобы после перезапуска проверить журнал аудита за время простоя.

## Что обрабатывается только в памяти и не сохраняется
- Сообщения: бот считает их количество и упоминания для анти-спама. **Текст сообщений бот не читает и не сохраняет.**
- Входы участников (для анти-рейда) и записи журнала аудита (для анти-краша) — хранятся в памяти не дольше нескольких минут.

## Зачем
Только для защиты сервера: обнаружения атак, наказания нарушителей и восстановления сервера. Данные не продаются, не передаются третьим лицам и не используются для рекламы или аналитики.

## Сколько хранятся
Резервных копий хранится не больше заданного владельцем сервера числа (по умолчанию 50), старые удаляются автоматически. Данные сервера не удаляются автоматически при удалении бота — чтобы удалить их, напишите нам.
